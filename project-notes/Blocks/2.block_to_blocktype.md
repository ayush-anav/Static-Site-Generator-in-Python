# 1. Headings
###### headings start with this very specific synatx `# `, it is # (with a space), check for that.
```py
    if block.startswith(("# ", "## ", "### ", "#### ", "##### ", "###### ")):
        return BlockType.HEADING
```

# 2. Code
###### code starts with ` ``` ` and ends with ` ``` ` BUT it is also multi-line so we need to handle that with a split operation to see if the last element also ends with ` ``` `.

```py
    multi_line = block.split("\n")
```

Now our code will look like: 
###### `["```", "code here", "return success", "```"]`
(FOR MULTI-LINE CODE, cause why wouldn't it be multi-line bruh)

```py
    if lines[0].startswith("```") and lines[-1].startswith("```"):
        return BlockType.CODE
```

---

# 3. Quote
> Quotes is where we will consider multi-line checking as well!

`for line in multi_line:`
```py
    if block.startswith(">"):
        for line in multi_line:
            if not line.startswith(">"):
                return BlockType.PARAGRAPH
            
        return BlockType.QUOTE
```

`here we will check line by line since each quote starts with > , and will have multi-line (we are accounting for this)`

---

# 4. Unordered List
- We will still use the multi-line stuff and the format is:
` - UL `

```py
    if block.startswith("- ")
        for line in multi_line:
            if not line.startswith("- "):
                return BlockType.PARAGRAPH

        return BlockType.UNORDERED_LIST
```

---

# 5. Ordered List
```py
    if block.startswith("1. "):
        i = 1
        for line in multi_line:
            if not line.startswith(f"{i}. "):
                return BlockType.PARAGRAPH

        return BlockType.ORDERED_LIST
```
