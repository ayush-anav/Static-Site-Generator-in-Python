### Blocks
###### Now that we are done cleaning our inline elements with proper TextNode representations, we can move over to block elements.

---

# Problem:
### We want to take input like:
```py
      md = """
This is **bolded** paragraph

This is another paragraph with _italic_ text and `code` here
This is the same paragraph on a new line

- This is a list
- with items
"""
```
### AND make it proper BLOCK level elements.

---

###### `This is very easy, split on \n\n, strip all space for each element in stripped, AND if its not "", append to block list (make a new list and append to that) and return that, basically taking input, splitting it on double newline, stripping whitepsace and returning it as block elements, cause they will be 3 diff elements in an array`
