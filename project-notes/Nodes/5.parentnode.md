# Parent Node
A parent node will have children, so we want a way  `to render these children`, THIS means we will use **recursion**.

## 1.0 Inital setup
```py
    class ParentNode(HTMLNode):
        def __init__(self, tag, children, props=None):
            super().__init__(tag=tag, value=None, children=children, props=None)
```
`Basically it is the opposite of a leaf node, a parent node WILL **NOT HAVE ANY VALUE THOUGH**`
#### Example
```html
    <ParentNode (can be whatever) PROPS /> <p>====</p> <b>BOLD</b> </ParentNode>
```
**`The formatting will be automatically done by code editor for HTML`**

---

### WHAT DO WE NEED?
- We need a way to access `each children in self.children` and for each child, we want to call `to_html`
- We need to `build our inner html with every call of child`
- We need to add OUR current `self.tag, self.props and return that nest after our loop and recursive call`

---

```py
    def to_html(self):
        if not self.tag:
            raise ValueError("tag not supplied")
        if not self.children:
            raise ValueError("this node needs children")

        inner_html = ""
        for child in self.children:
            inner_html += child.to_html()

        return f"<{self.tag}{self.props_to_html()}>{inner_html}</{self.tag}>"
```

***`We are constructing inner_html, with each recursive call to it`***
