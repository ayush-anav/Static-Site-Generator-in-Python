# Render Leaf Node

---

### SUMMARY OF SECTION
`a leaf node is a node that has no children, it is its own lone node and can be rendered easily.`

---

#### A leaf node = 
- has no children AT ALL, cannot have ANY.

```html
<p>some text goes here</p>
<p>this is not leaf node, <a>THIS IS LEAF NODE</a> <--, that is</p>
```

## 1.0 Create a Leaf Node Class, that inherts from HTMLNode, since all leaf is still a HTMLNode
#### children property should NOT be allowed
#### TAG and VALUE must be given, props remains optional

```py
    class LeafNode(HTMLNode):
        def __init__(self, tag, value, props=None):
            super().__init__(tag=tag, value=value, children=None, props=props)
            self.tag = tag
            self.value = value
            self.props = props
```

# LEARNING MOMENT
### Inherting from Parent and **PASSING OPTIONAL PARAMETERS**

#### We can inherit from parents and still make our `parameter passing optional by employing keyword arguments in the class constructor and passing keyword args to the super() call.`  

###### This means that for inside the class, we use keyword args and for objects that `create class, we have to still use positional arguments`, `though we can also turn that to keyword by doing var_name = val`, forcing users to use keyword args when creating obj `(NOT NEEDED)`

```py
# props default to none when no positional arg given
def __init__(self, tag, value, props=None):
        # uses keyword args to hand to super(), allowing us to make children FORCED to NONE
        super().__init__(tag=tag, value=value, children=None, props=props)
```
### When we create an object, we are using POSITIONAL args, `internally its using KEYWORD args to pass to SUPER()`

#### EXAMPLE
```py
node_a = LeafNode("a", "click to hack", {"href", "http://localhost:8080"})
```
#### This still uses keyword args, `internally handsoff nicely.`

## Note:
#### when inheriting, when we just pass in the `parent class as super class`, `by default ALL METHODS will be INHERITED.`
#### `ARGUMENTS require super().__init__()`, NOT METHODS, they come with regardless.

## 2.0 Render the HTML LeafNode, first checking (OVERRIDE to_html()):
- if **no tag**, `that means it is just plain text`, return the text *self.value*
- if **no value**, ` raise ValueError("all tags must have a value") `.
- else, **render out our html leaf node**

```py
    def to_html(self):
        if not self.tag:
            return self.value
        if not self.value:
            raise ValueError("all tags must have a value")
        return f"<{self.tag}{self.props_to_html()}>{self.value}</{self.tag}>
```
