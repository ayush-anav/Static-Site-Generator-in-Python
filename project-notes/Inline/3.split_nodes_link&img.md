## Core Algorithm
- take a list of old_nodes that we will process
- for each node.text, apply **regex to get our `matches for *![]()* img or *[]()* link`**
- create a fragment 
```py
    current_text = node.text
    matches = extract_markdown_links(current_text)

    for link_text, link in matches:
        fragment = f"{before}{after}"
        # do a max split of 1
        before, after = current_text.split(fragment, 1)
        
        if before: 
            new_list.append(TextNode(before, TextType.TEXT))
        
```
#### `we can now access our link`
```py
    new_list.append(TextNode(link_text, TextType.LINK, link))

    current_text = after
    # when the for-loop runs again (if there are more links, it will split from after because we already)
    # (recorded our fist Link, we need to record MORE!)
```
###### `current = after makes sure that our after section will split even more if there are more matches`
###### `e.g [first_half, link_pair, AFTER_portion_that_may_have_more_links]`
##### AFTER our for-loop ends, we will check if current exists, then append that to the new_list we returning.
```py
    if current:
        new_list.append(TextNode(current, TextType.TEXT))
```
